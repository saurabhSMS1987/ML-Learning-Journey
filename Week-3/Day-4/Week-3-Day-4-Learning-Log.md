### Machine Learning Paradigms

**Supervised Learning:**
- Learning with labeled data
- Regression (continuous output)
- Classification (discrete output)
- Examples: Linear regression, decision trees

**Unsupervised Learning:**
- Learning without labels
- Clustering (group similar data)
- Dimensionality reduction
- Examples: K-means, PCA

**Reinforcement Learning:**
- Learning through interaction
- Rewards & penalties feedback
- Decision-making under uncertainty
- Examples: Game AI, robotics

**Deep Learning:**
- Neural networks with multiple layers
- Feature learning automatically
- Powerful for complex data
- Examples: CNNs, RNNs, Transformers

### Multiple Linear Regression

**Concept:** Predict continuous values using multiple features
```
y = b0 + b1*x1 + b2*x2 + ... + bn*xn
```

**Key Assumptions:**
- Linearity: Linear relationship between features & target
- Homoscedasticity: Constant variance of residuals
- Independence: Features independent of each other

**Handling Categorical Variables:**
- Dummy variable encoding
- One-hot encoding
- Avoiding multicollinearity

**Statistical Significance:**
- P-values: Probability feature has real effect
- Threshold: p < 0.05 typically significant
- Hypothesis testing for feature importance

**Building Robust Models:**
- Feature selection & engineering
- Handling outliers & missing values
- Model validation & evaluation
- Avoiding overfitting
